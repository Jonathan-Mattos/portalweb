Quem eu estou estilizando? (Seletores CSS)

    
    

      
      
      

        
1. Seletor de Elemento (Tag)

        
Aplica o estilo a todas as tags do mesmo tipo.

        p { color: red; }
        


        
Sou um parágrafo <p>

      


      
      

        
2. Seletor de Classe (.nome)

        
Aplica a vários elementos que compartilham a mesma classe.

        .destaque { bg: roxo; }
        


        class="destaque"
      


      
      

        
3. Seletor de ID (#nome)

        
Exclusivo para um único elemento na página.

        #unico { color: amarelo; }
        


        id="unico"
      


      
      

        
4. Estado de Interação (:hover)

        
Altera o estilo quando o mouse passa por cima.

        button:hover { bg: verde; }
        


        Passe o mouse aqui!
